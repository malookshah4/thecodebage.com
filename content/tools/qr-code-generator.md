## Settings that affect scanning

**Error correction** lets a QR code still work when part of it is dirty, scratched or covered. Level L can recover about 7% damage, M about 15%, Q about 25% and H about 30%. Higher levels add more modules (the little squares), so the code gets denser. For a link on a screen, M is fine. For a sticker on a shop counter or a sign that will sit in the sun, use Q. Use H if you will put a small logo in the middle.

**Margin** is the empty border around the code, called the quiet zone. The QR standard asks for 4 modules. Scanners use it to find where the code starts. Setting it to 0 looks neat in a design tool, but if you then place the code on a busy background, many phones will fail to read it.

**Colors** matter more than people expect. Scanners look for contrast between dark and light, so a pale yellow code on white, or dark blue on black, can fail. The tool warns you when the contrast is too low. Light codes on dark backgrounds (inverted) work on most new phone cameras but not on every scanner app, so dark on light is still the safe choice.

**Data length** sets how dense the code is. A short link gives a chunky code that scans from far away. A long paragraph needs a bigger print. Keep printed codes at least 2 cm wide.

## WiFi codes and contact cards

A WiFi QR code lets guests join your network by pointing their camera at it, without you spelling out a long password. It works on recent iPhones and Android phones from the built-in camera. The network name and password are case sensitive, so "HomeWiFi" and "homewifi" are different networks. Special characters like semicolons and colons are escaped for you.

A contact card QR code uses the vCard format. When someone scans it, their phone offers to save you as a new contact with your name, company, phone, email and website filled in. For phone numbers, include the country code, like +92 for Pakistan, so the number works for visitors too.

## FAQ

### Is this QR code generator free, and do the codes expire?

It is free with no sign-up, and the codes never expire. The data is inside the image, not behind a short link on someone's server.

### Is my WiFi password sent anywhere?

No. The code is generated in your browser on your device. Nothing you type is uploaded or saved.

### PNG or SVG, which should I download?

Use PNG for websites, WhatsApp, Instagram and slides. Use SVG for print, because it is vector and stays sharp at any size, from a business card to a banner.

### Can I change the link after printing?

Not with a static code. The link is part of the pattern, so a new link means a new code. Services that let you edit later use a redirect link, which stops working if that service shuts down or you stop paying.
